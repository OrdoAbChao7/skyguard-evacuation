## 4. 解释边界

- 合成机制不等同真实人群动力学；点预测仍是 V7.0 集成，未重新训练；
- ACI 的目标是覆盖校准，不是降低 MAE；MAE 不变是预期结果；
- 区间不是正式统计置信区间；即使覆盖改善，也不得直接用于安全告警阈值；
- 可靠性门控失败时，预测不得进入 VoI/规划；安全四态仍由观测可信度决定。
