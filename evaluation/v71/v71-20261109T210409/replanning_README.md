- **性能提升是否主要来自滚动重规划？** B vs A：未疏散差 -682.8267，完成时间差 -5.1133。
- **预测是否提供额外信息价值？** G vs F（仅加预测）：未疏散差 0，完成时间差 -0.0267；E vs D 见配对表。

- **MPC 是否存在不必要计算成本？** C vs B：求解耗时差 -0.5267 ms，重规划次数差 -2.5733，未疏散差 0。
- **复杂算法何时不如简单基线？** D vs B：未疏散差 0，求解耗时差 0.5467 ms；若差值为正且 CI 跨零/为正，则复杂算法无优势或更差。

## 6. 解释边界

- 所有结果来自合成场景与未标定拥堵参数；BPR/服务衰减/事件阈值均为启发式；
- 预测误差模型显式声明；不得把本实验解释为真实预测系统收益；
- 负向/混合结果保留在 `replanning_rows.json`；
- 复杂算法“更差”同样是有价值结论，不得删除。
