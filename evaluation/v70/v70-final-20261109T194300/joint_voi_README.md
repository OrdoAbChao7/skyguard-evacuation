## 3. 敏感性与预算

- 相关性参数（benefit / worst risk / detection）：0: 0.18 / 0.1011 / 0.7597；0.5: 0.177 / 0.1007 / 0.7584；0.8: 0.1755 / 0.1012 / 0.7578。
- 预算 1/2/3（benefit / cost / actions）：1: 0.1417 / 0.5213 / 1；2: 0.177 / 0.5836 / 1.9225；3: 0.1834 / 0.627 / 2.4925。
- 预算增加会提高收益与成本；不得只引用收益而不引用成本。

## 4. 解释边界

- 真实状态按 0.5 概率共享潜在因子生成；这是**合成相关性**，不是真实人群风险传播规律。
- 联合 VoI 是启发式近似（相关性 + 冗余折扣），不是联合 POMDP 精确解。
- 若 Holm 校正后不显著，只能报告“未发现明确优势”，不能宣称联合 VoI 全面优于现有多区域 VoI。
- 负向或混合结果必须保留；`joint_voi_rows.json` 含全部逐 trial 记录。
