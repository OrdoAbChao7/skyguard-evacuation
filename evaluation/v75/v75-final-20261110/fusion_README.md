## 解释边界

- 传感器噪声、可靠度、时间戳偏移均为合成注入；
- “决策准确率”只衡量是否在该拒绝时拒绝、该融合时融合，不衡量真实安全后果；
- 偏置条件用于检验可靠性加权对持续偏置的敏感性：偏置不是冲突，加权无法消除；
- 不得表述为真实摄像机/无人机融合精度。
