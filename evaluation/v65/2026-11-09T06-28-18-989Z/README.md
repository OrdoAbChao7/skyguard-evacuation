## 3. 关键观察

- 各机制 MAE 最佳方法：stable=linear (10.1645)；surge=persistence (93.458)；decline=linear (8.425)；periodic=linear (81.8624)；missing=ema (12.4024)；noisy=linear (70.7293)。
- 自适应在配对平均上优于全部基线（见第 2 节，差值为负），但**不是任何单一机制的最佳方法**；这支持“按场景自适应、不宣称全面最优”的表述。
- 与 persistence 相比：stable 优于或持平（11.3356 vs 13.8813）；surge 劣于（97.8812 vs 93.458）；decline 优于或持平（9.6332 vs 32.3978）；periodic 劣于（105.3382 vs 89.8419）；missing 优于或持平（13.3688 vs 15.6055）；noisy 优于或持平（79.0271 vs 93.0437）。
- 95% 覆盖率：stable 0.9968，surge 0.9086，decline 0.9925，periodic 1，missing 0.995，noisy 1。**surge 明显低于名义 95%**，其余机制接近或高于名义；不得把区间用于安全告警阈值。
- surge 分段（自适应）：起点 <38 覆盖率 0.8786、MAE 35.91、平均宽度 250.0019；起点 ≥38 覆盖率 0.9333、MAE 148.9163、平均宽度 1548.7409。**两段都欠覆盖**，说明不是可忽略的尾部噪声，而是模型失效。
- 失效检测率（区间相对宽度 > 0.5）：stable 0.743，surge 0.8968，decline 0.671，periodic 1，missing 0.7444，noisy 1。periodic/noisy 下预测动作几乎总被阻断，说明可靠性门槛确实会阻止不可靠预测进入 VoI。
- 失败样本保留在 `rows.json` 与 `worst_cases`；未按结果删除场景或种子。

## 6. 边界

- 合成机制不等同真实人群动力学；未使用 ShanghaiTech/CityStreet 时间序列（它们没有本仓库可用的人工时序真值）。
- 预测区间由滚动残差分位近似，不是正式统计置信区间。
- 方法选择只在训练窗口内进行；测试目标点未参与选择。
- 预测可靠性 failed 时，VoI 预测动作不可用；安全四态仍由观测可信度决定，不被预测替代。
