## 修正内容

1. 所有策略对同一物理动作获得**相同覆盖区域**；V6.2 中 `single` 只覆盖目标区域，UAV 的 neighbors 覆盖被抹掉。
2. 观测结果从 `P(outcome | hypothesis, action)` **采样**，不再取最大似然标签。
3. 预算准入统一为 `used + candidate <= max`。
