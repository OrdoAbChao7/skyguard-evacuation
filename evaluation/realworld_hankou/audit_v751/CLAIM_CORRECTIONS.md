# V7.5.1 对外主张逐条修正表 (CLAIM_CORRECTIONS)

**用途**: 将 `evaluation/realworld_hankou/` 原报告中的对外主张逐条对照代码、原始数据与复现结果，给出 PASS / PARTIAL / BLOCKED / FAIL 判定与可直接替换的表述。  
**原则**:

- **PASS**：仓库内证据充分，可按原口径使用；
- **PARTIAL**：方向成立，但必须加限定条件/来源等级；
- **BLOCKED**：仓库内无法核实，必须补外部证据，**不得写成已验证**；
- **FAIL**：与代码/原始数据矛盾，或证据不足却作确定性表述，**必须删除或重写**。

> 本表只修正**表述**，不修改原始实验数据、不修改算法参数、不修改已冻结的 V7.2/V7.3/V7.4/V7.5 证据文件。
