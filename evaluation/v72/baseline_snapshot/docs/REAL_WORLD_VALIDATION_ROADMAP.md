# 真实世界验证路线

> 原则：每一级验证必须有证据才能升级；不得跳级宣称。

## 阶段 0：合成闭环（已完成）

- 合成体育场场景、回放/模拟观测、MVP 三场景、V6/V6.1/V6.2 统计实验。
- 证据：`evaluation/v62/`、`evaluation/V6_2_REPORT.md`。

## 阶段 1：公开单数据集（已完成，2026-11-05）

- ShanghaiTech Part A test，P2PNet SHTechA 官方权重，CPU。
- 结果：MAE 57.2418 / RMSE 96.0415 / NAE 0.1319；复跑 182/182 一致。
- 证据：`evaluation/real-data/`。
- 边界：单一数据集/权重；许可未核验；非自训练模型。

## 阶段 2：多数据集与对照（下一步）

- NWPU-Crowd、UCF-QNRF、ShanghaiTech Part B；
- CSRNet 对照；
- 密度/场景分层、遮挡/视角分析；
- 通过标准：官方 split、无测试泄漏、per-image 结果可复算、许可核验。

## 阶段 3：真实视频与摄像机标定

- 固定机位视频，人工标注若干帧；
- 像素→平方米标定，区域 ROI；
- 多摄像头重叠去重；
- 通过标准：标定记录、标注一致性、误差分析。

## 阶段 4：场馆测绘与容量标定

- 区域面积、通道容量、出口容量、人员配置；
- 现场记录与不确定性；
- 通过标准：measured 字段与来源可追溯。

## 阶段 5：受控演练

- 小规模受控场景，人工审批与反馈闭环；
- 安全评审与失效模式分析；
- 通过标准：演练记录、异常处置、复盘。

## 阶段 6：正式评审

- 消防/公共安全/功能安全评审；
- 不通过不得称“生产可用”。
