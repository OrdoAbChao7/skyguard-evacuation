> 日期：2026-11-10。审查对象：V7.2 路线稳定性、承诺式求解、场馆标定、Shadow 回放与华为状态链路。
> 所有问题均给出可复现测试或证据路径；未修复项明确标注残余风险。
> 本报告不构成安全认证，也不代表真实场馆演练。

## 2. 主要发现与处置

### P0-1 双向通道容量超限（已修复）

**问题**：时间扩展求解器给双向通道每个方向全额容量；独立校验器与执行模型按同一走廊每分钟总量计算。
构造用例可让 C_MID 双向合计 220 > 180，计划在物理上不可执行。

**修复**：求解器迭代分配共享容量（最多 8 轮），并显式接收「已承诺流量」；
核心按 `名义容量 − 已用` 建弧；稳定求解器传递已用容量。

**回归**：`v72-redteam.test.ts` 对双向场景 8 组随机需求做逐分钟容量复核 + 独立校验。

### P0-2 承诺候选合并后超容量（已修复）

**问题**：逐区域承诺求解的容量预留与自由求解叠加后仍可能超容量；若直接采用会发布不可执行方案。

**修复**：合并后逐分钟容量复核；冲突时承诺份额 0.8→0.6→0.4→0.2 递减重解；
仍冲突则返回 `capacity_violations`，MPC 必须拒绝。

**回归**：`v72-stability` 容量校验；`v72-redteam` 极速需求显式报告冲突。

### P1-1 V7.1 稳定化接口语义错误（已修复/解释）

**问题**：`allowedExitsByRegion` 在求解器中按「出口所属区域」生效，无法表达「来源区域只能走某出口」；
V7.1 的路线稳定启发式因此基本无效（H 切换 4960 vs G 4745 的负结果）。

**修复**：V7.2 不再依赖该接口，改用承诺式逐区域求解；
V7.1 负结果保留，并解释为接口语义限制而非稳定性本身无效。

**回归**：`v72-stability` 承诺窗口降低切换；`v72-redteam` 容量与紧急覆盖。

### P1-2 预测输入污染（已修复）

**问题**：NaN/Infinity/超大预测到达可能进入求和、队列与指标，产生 NaN 或荒谬值。

**修复**：MPC 对 `offsetMinute`/`persons` 做有限性检查，人数夹紧到 10,000,000；负数跳过。

**回归**：`v72-redteam` 预测突变，断言所有指标有限。

### P1-3 相机观测伪造（已修复）

**问题**：离线相机、未来时间戳、非法接收时间未被适配器拒绝。

**修复**：`adaptCameraCount` 增加 `camera_offline`、`timestamp_in_future`（30 秒容差）、`invalid_timestamp`。

**回归**：`v72-redteam` 相机攻击。

### P2-1 Shadow 超时非抢占（保留）

超时是求解完成后检查 `solveMs > maxSolveMs`，不是运行中抢占。
预算为零会立即回退；真正的抢占需要 worker/子进程。已在 Shadow 文档与审计中标注。

### P2-2 Shadow 记录仅内存（保留）

进程重启丢失比较记录；不影响安全发布。若用于长期运营比较，需要持久化与保留策略。

### P2-3 合成标定不能替代真实标定（保留）

标定流水线能表达真实参数，但当前只有合成档案；所有估计值被降级为 `estimated`。
没有真实摄像机、授权数据或现场测绘。

## 3. Shadow 安全结论

- V7 方案永不发布；legacy 方案与四态不受 Shadow 影响；
- 两套方案都经独立校验；异常/超时/校验失败/预算为零均回退；
- 快照人数不一致会被标记，禁止 `v7_eligible_for_review`；
- 过期观测下两套方案均不可发布；
- Shadow 仍默认关闭，未启用，不是安全批准。

## 4. 残余风险

| 风险 | 级别 | 说明 |
| --- | --- | --- |
| 稳定性增加区域密度/队列 | P1 | 本实验最大密度 +0.07–0.08；需现场阈值与人工审查 |
| 贪心承诺非联合最优 | P1 | 容量紧张时收益消失或被拒绝 |
| 双向共享迭代非全局最优 | P2 | 不保证所有场景收敛；最终有容量复核兜底 |
| 事件阈值/惩罚参数未标定 | P1 | 10/人、0.05、6 分钟均为实验值 |
| 无真实场馆/硬件/平台 | P0（外部） | 不得宣称生产就绪或实机结果 |

## 5. 结论

V7.2 修复了两个会导致「计划在物理上不可执行」的 P0 问题，并把稳定性机制置于
「未疏散不增加 + 容量复核 + 目标护栏 + 紧急覆盖」四重约束下。
剩余风险主要是参数未标定、贪心近似与外部验证缺失，均已登记，不得用合成结果替代真实验证。
