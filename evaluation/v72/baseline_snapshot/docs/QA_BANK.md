# 答辩问题库（20 问）

1. **为什么不让大模型直接规划路线？**
   安全结论必须是确定性的。Agent 只组织工具；规划器与独立 Validator 负责路线，大模型不参与约束判定。

2. **AgentArts 接入了吗？**
   适配器、健康探测、契约测试、运行时接线已完成；**没有真实租户/官方 API 文档，未实机连接**。界面显示 `LOCAL DEMO`。

3. **VoI 一定优于固定优先级吗？**
   不一定。实验显示 VoI 成本更低（1.77 vs 3.57 分钟），但风险降低略低（0.0486 vs 0.0572）。这是信息-成本权衡。

4. **VoI 参数从哪来？**
   全部来自场景 JSON 的 `investigation`，加载时校验归一化；不是大模型生成。

5. **预测准确率多少？**
   没有真实标注数据，不能给真实准确率。合成基准：5 分钟自适应 MAE 59.5，持久化 58.5；区间覆盖率 84%。

6. **为什么预测有时不如持久化？**
   合成序列含突发高斯峰，历史外推无法预测突变；自适应选择会退化为持久化/EMA。这是已知局限。

7. **视频计数精度？**
   CPU 路径是运动前景计数，无标注验证；不能声称准确率。接入 P2PNet/CSRNet 需要公开数据+现场标定。

8. **怎么防止 Agent 越权？**
   Agent 只能创建 `PENDING_APPROVAL`；审批/派发需 admin/safety_operator；接单/反馈需 staff 且只能操作本人工单；MCP 与本地共用权限注册表。

9. **审批后现场又变了怎么办？**
   工单记录观测/约束/场景版本；变化后标记 `stale`，派发被阻断，管理员必须重新确认。

10. **未知通道/容量怎么处理？**
    规划排除，校验若使用则报硬违规；未知不当作可用。

11. **为什么会出现 REJECT？**
    独立校验发现未解决需求（出口/通道容量不足）。REJECT 下不发布路线，只显示候选与原因。

12. **四态优先级？**
    `DEGRADED > REJECT > REROUTE > NORMAL`；数据不可信时不下“不可行”结论。

13. **MCP 工具安全吗？**
    Zod Schema、角色、超时、审计、结构化错误码、幂等键；无文件/命令能力；生产仍需网关鉴权。

14. **能换场景吗？**
    能。区域/通道/出口/规则/人员/无人机/调查策略/工具清单都在 JSON；体育场逻辑未写死。

15. **能支撑多少并发？**
    当前单进程内存状态，适合演示/单点；多实例需要共享存储、分布式限流与审计汇聚。

16. **数据隐私？**
    当前全是合成数据；真实视频需脱敏、最小化留存、访问控制与合规评估。

17. **如果模型/网络不可用？**
    本地确定式 Agent 与安全内核可离线运行；AgentArts 不可用会显式失败，不伪装。

18. **为什么不用强化学习？**
    安全关键场景需要可解释、可审计、可测试；VoI/规则更容易验证与复现。

19. **实验是否选择性报告？**
    报告均值+置信区间、失败案例、覆盖率不足与预测弱点；原始 JSON 可复现。

20. **距离真实部署还差什么？**
    真实测绘与标定、真实视频/人流、AgentArts 租户、昇腾设备、无人机、持久化/多实例、安全认证与演练。
