# V7.1 公开数据集候选与许可核验

> 日期：2026-11-09。目的：为人群计数、轨迹、拥堵传播与时序预测寻找可用的公开数据，
> 明确入口、许可、划分与使用限制。**未下载或分发新数据集**；下列状态来自 2026-11-09 的页面访问。

## 1. 核验状态定义

- **VERIFIED**：页面可访问且许可/条款明确；
- **PARTIAL**：入口可访问，但许可或数据条款不完整；
- **UNVERIFIED**：页面证书过期、404、访问失败或未找到明确许可；
- **禁止**：不得把静态图片计数精度表述为动态疏散预测精度。

## 3. 与 SkyGuard 研究问题的匹配度

| 研究问题 | 可用公开数据 | 不能证明什么 |
| --- | --- | --- |
| 图像→人数感知 | ShanghaiTech、NWPU-Crowd、UCF-QNRF、JHU-Crowd++ | 不能证明区域密度、时序预测或疏散效果 |
| 轨迹/运动模式 | ETH/UCY、SDD、MOT20 | 不能给出 SkyGuard 的 zone/corridor/exit 决策标签 |
| 拥堵传播 | 轨迹数据可构造代理指标 | 没有真实疏散队列/出口服务率真值 |
| 时序预测 | 轨迹/计数序列可做跨域实验 | 不等于真实场馆人流；不得把图片计数 MAE 当作预测精度 |
| 疏散策略/规划 | **未找到公开的、带 SkyGuard 区域-通道-出口决策标签的数据集** | 仍必须使用合成场景与明确标注的模拟实验 |

## 4. 使用限制与后续动作

1. 任何新数据集使用前必须再次核验许可、划分与引用要求；不得把仓库代码许可等同于数据许可；
2. 不随仓库分发原始数据；只提交派生统计与可复现脚本，并标注来源与许可状态；
3. 公开数据实验与合成实验必须分开报告，禁止混合统计；
4. 静态图片计数精度不得表述为动态疏散预测精度；
5. 若后续获得场馆协作，需要另行完成摄像机标定、区域测绘、通道/出口容量测量与真实演练。

## 5. 结论

- 公开数据足以支持“感知/轨迹”层面的跨域研究；
- **没有公开数据能替代 SkyGuard 的疏散决策验证**；
- V7.1 的预测与规划结论仍限定在合成机制/场景，不得升级为真实场馆效果。
