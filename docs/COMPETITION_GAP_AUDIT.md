# SkyGuard V7.4 竞赛差距审计

> 日期：2026-11-10。对照华为 ICT 创新赛常见评审维度（创新性、技术深度、工程实现、华为生态、
> 真实场景价值、可复现与证据）做差距盘点。**不预测名次，不声称获奖。**

## 1. 总览

| 维度 | 现状 | 差距等级 | 说明 |
| --- | --- | --- | --- |
| 创新性 | 执行感知承诺门控 + Pareto 份额 + 风险释放；有负结果 | 中 | 机制新颖度有限；需与文献明确区分 |
| 技术深度 | 时间扩展 MPC、双向容量、四态校验、标定质量、检测对照 | 中 | 缺真实数据与理论分析 |

## 2. 关键差距

### 2.1 华为生态（最高优先级）

- **AgentArts**：只有本地 stub 与契约测试；无租户、API Key、平台 Trace。比赛若要求「真实调用」，
  当前材料只能写「适配器就绪、未接入」。
- **昇腾**：无 `npu-smi`/`atc`/CANN/OM；只有 ONNX checker 与 CPUExecutionProvider 基准。
  不能把 0.0112ms 写成 NPU 性能。
- **可补动作**：申请沙箱租户；在可用 NPU 上跑 ATC→OM→推理并记录设备/驱动/CANN 版本、
  `.om` SHA-256、p50/p95、数值一致性。

### 2.2 真实数据（最高优先级）

- 场景、入流、误差模型均为合成；标定为夹具；检测为合成序列；
- ShanghaiTech 仅用于计数评测（MAE 57.24），不是疏散真值；
- **可补动作**：取得许可的真实场馆拓扑/容量/摄像机；至少一个匿名化人流序列；
  做时钟同步与容量标定，并区分 `measured/estimated/uncalibrated`。

### 2.3 算法创新（中）

- V7.4 的核心正结果是「有界代价的稳定性」，负结果是「零代价不可得」「风险折扣无效」；
- 与文献（MPC、承诺、迟滞、Pareto）区分度需要更明确的相关工作与消融；
- **可补动作**：补充敏感性网格（门控容差、份额、风险阈值）；与至少一个外部基线对比。

### 2.4 工程与部署（中低）

- Docker daemon 不可用，未构建镜像；CI 未在平台实跑；
- 负载仅状态端点；E2E 仅冒烟；
- **可补动作**：在可用 Docker 环境构建/运行；CI 跑通；补写操作与故障恢复 E2E。

### 2.5 安全与评审（低-中）

- 内部红队与回归充分，但无第三方安全评审、无真实演练；
- **可补动作**：邀请安全/应急领域专家评审；做一次桌面演练并记录。

## 3. 已有优势（应保留）

1. 证据治理：SHA-256 清单、冻结基线、只读校验、负结果登记；
2. 安全边界：Agent 不能审批/派发；四态；独立校验；未知不可用；
3. 可复现：一条命令生成 31 文件证据；
4. 诚实边界：BLOCKED/NOT_SUPPORTED 明确，未包装。

## 4. 对外表述建议

- **可以写**：研究原型、合成实验、可复现有界收益、适配器就绪、CPU 基准、证据治理；
- **必须限定**：所有效果为合成；稳定性有代价；检测误报未改善；
- **不能写**：已接入 AgentArts、已在昇腾运行、真实场馆验证、零代价稳定性、可获一等奖。
