# SkyGuard V7.3 演示方案（竞赛/答辩）

> 目标：在 8–10 分钟内展示“感知—预测—调查—规划—校验—审批—执行—反馈—重评估”闭环，
> 同时明确区分**已实现/合成**与**真实能力**。不得把合成结果说成真实场馆效果。

## 1. 演示前状态

| 项 | 演示值 | 性质 |
| --- | --- | --- |
| 场馆 | `data/scenarios/stadium-evacuation.json` | 合成场景（面积/容量/位置未测绘） |
| 版本 | `v7.3.0-research.1` | 研究原型 |
| Shadow | 默认关闭 | 可选演示只读比较 |
| AgentArts | `not_configured` | 本地 stub；不声称实机 |
| Ascend | 无 NPU | ONNX CPU 基准；不声称 NPU |

## 2. 十步演示脚本

### 步骤 1 场馆配置

- 展示场景 JSON：区域、走廊、出口、容量、相机映射；
- 运行 `v73-venue-import` 的拓扑校验/方向性容量/约束比较；
- 说明：容量与面积是合成/未标定；真实部署需测绘与授权数据。

### 步骤 2 人群观测

- 通过 API 写入模拟观测（或 CSV replay）；
- 展示观测来源、置信度、标定版本、时效；
- 触发一次低置信度/过期观测，展示被拒绝。

### 步骤 3 短时预测

- 调用预测预览，展示点预测 + 区间 + 可靠性门控；
- 说明：surge 区间覆盖不足，门控失败时预测不得进入规划。

### 步骤 4 风险评估

- 展示区域密度/风险等级、传播邻域；
- 触发 crowd_surge 事件，展示风险上升与四态变化。

### 步骤 5 主动调查（VoI）

- Agent 创建调查工单（待审批），展示 VoI 选择与成本；
- 说明：Agent 不能审批/派发无人机。

### 步骤 6 动态疏散规划

- 运行 MPC 预览：标准 MPC vs 自适应稳定性；
- 展示切换人数、振荡人数、完成时间、队列、密度；
- 展示 V7.3 自适应：切换 −64%、振荡 −84%，代价 +0.96 分钟；
- 强调：合成数据、参数未标定。

### 步骤 7 独立安全校验

- 展示 Validator 硬约束（容量、版本、未知/不可用、观测可信）；
- 注入出口故障/通道封控，展示计划避让与校验通过；
- 注入冲突观测，展示跳过规划/不可信状态。

### 步骤 8 人工审批

- 展示待审批工单、审批人/角色、审计记录；
- 拒绝一次审批，展示不可执行；
- 说明：四态与人工审批未被 V7 绕过。

### 步骤 9 工单执行与反馈

- 审批后执行工单，写入反馈；
- 展示反馈进入重新评估，版本递增；
- 说明：执行是演示/模拟，不是真实人员调度。

### 步骤 10 反馈与重评估 + Shadow 对比

- 重新规划，展示计划版本失效/重建；
- 可选开启 Shadow（只读 API），展示 legacy/V7 同快照比较、路由切换、回退原因；
- 强调：V7 不发布；Shadow 默认关闭；`v7_eligible_for_review` 不是安全批准。

## 3. 演示命令

```bash
npm run demo
npm run demo:mvp
npm run benchmark:v73 -- --only=stability
npm run benchmark:v73 -- --only=calibration
npm run benchmark:v73 -- --only=shadow
npm run benchmark:v73 -- --only=ascend
npm run benchmark:v73 -- --only=agentarts
npm run verify:evidence
```

## 4. 明确不能演示/不能宣称

- 真实场馆疏散效果、真实预测精度；
- AgentArts 实机 Trace/审批/反馈；
- 昇腾 NPU/OM 性能；
- 无人机实机控制；
- 国一或任何竞赛名次。

## 5. 答辩一句话

“我们把预测、规划、稳定性、校验和 Shadow 做成可复现、可证伪、带安全护栏的研究原型；
真实场馆、平台与硬件验证仍是下一步，不会用合成结果替代。”
