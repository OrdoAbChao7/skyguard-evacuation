# 技术答辩问题库（30 问）

1. **VoI 的数学定义？** 贝叶斯后验 + 熵 + 预期风险损失降低 − 时间/资源/失败成本；参数全部来自场景。
2. **VoI 一定更好吗？** 不。模拟中成本更低，但风险降低略低；多区域总收益高、单位效率可能低。
3. **概率从哪来？** 场景 JSON 的先验/似然/损失矩阵，加载时校验归一化；LLM 不生成。
4. **证据冲突怎么办？** 10 分钟窗口内相反信息性证据标记冲突，后验与先验 50/50 折扣。
5. **调查失败怎么办？** 最大尝试次数 + 冷却 + 指数退避；预算耗尽停止。
6. **多区域模型是什么？** 区域图 + 容量/距离边权 + 风险传播 + 覆盖权重；是启发式，不是人群动力学。
7. **多区域一定更优？** 同预算总风险降低约 6.3×，成本约 7.7×，效率无显著差异；适用条件明确。
8. **为什么需要独立 Validator？** 规划器不能自我认证；Validator 自行重建 15 类硬约束。
9. **故障注入结果？** 5/5 检出（超容量、未知出口、未知通道、负人数、重复 route id）。
10. **四态优先级？** DEGRADED > REJECT > REROUTE > NORMAL；数据不可信不下“不可行”结论。
11. **Agent 会越权吗？** 只能创建待审批工单；审批/派发需 admin/operator；接单/反馈需 staff 且仅本人工单。
12. **审批后环境变化？** 工单记录上下文版本，变化后 stale，派发阻断，管理员 revalidate。
13. **重复调用会产生重复任务吗？** 幂等键；MCP 测试验证重复创建返回同一工单。
14. **预测方法？** v3 滚动验证选择 persistence/EMA/linear/damped/blend；区间用 h 步误差 95 分位 ×1.5。
15. **预测准确率？** 无真实标注，不能给真实精度；合成 5 分钟自适应 MAE 59.5，持久化 58.5。
16. **区间覆盖率？** 2/5/10 分钟约 91.5%/84.1%/79.1%，未达 95%，不能用于安全告警。
17. **邻居信息预测？** 合成相关序列相对改进 4.8%/5.1%/8.4%；真实场景未验证。
18. **人群计数精度？** CPU 路径是运动前景计数，无标注；不能声称准确率。
19. **如何接入 P2PNet/CSRNet？** 提供数据集/标注/评测 CLI（MAE/RMSE/NAE、定位 P/R/F1），未附带数据与权重。
20. **MCP 安全？** Zod Schema、角色、超时、审计、结构化错误码、幂等；无文件/命令能力。
21. **AgentArts 接入了吗？** 适配器/健康探测/契约/运行时接线完成；无租户与官方 API 文档，**未实机**。
22. **昇腾状态？** 仅环境探针与外部推理契约；无 NPU/CANN/`.om`，未实机。
23. **无人机？** 工单请求/审批/模拟反馈；无真实飞控。
24. **场景能换吗？** 能。区域/通道/出口/规则/人员/无人机/调查策略/工具清单都在 JSON。
25. **并发能力？** 单进程内存状态；限流是进程内；多实例需共享存储/分布式限流。
26. **持久化？** 可选工单 JSON 快照（非数据库，无事务）；安全状态仍在内存。
27. **统计数据怎么保证？** 固定种子、多种子、Bootstrap 置信区间、原始 JSON、失败案例。
28. **实验是否选择性报告？** 报告弱点：预测突增差、区间不足、VoI 权衡、多区域效率。
29. **真实数据边界？** 没有真实场馆/人流/视频/平台/硬件；全部合成。
30. **距离全国一等奖还差什么？** 真实场景测绘与数据、AgentArts 租户实机、CANN 设备、公开数据集评测、正式安全评审与演练。
