# 技术报告 / 论文大纲

## 标题（建议）

SkyGuard：面向大型活动散场的风险感知主动调查与可信人机协同系统

## 摘要要点

- 问题：散场场景中信息不完整、风险演化快、调度依赖人工经验；
- 方法：VoI 主动调查 + 可解释短时预测 + 时间扩展流规划 + 独立校验 + 审批/反馈闭环；
- 证据：多随机种子实验、故障注入、端到端闭环；
- 边界：合成数据、未实机连接 AgentArts/昇腾。

## 1. 引言

- 大型活动散场的三类失败：物理常识盲区、时效错配、信息不可信；
- 现有系统：监控大屏/对讲机/经验调度，缺少“何时调查、调查什么”的量化依据；
- 贡献：三个创新 + 可复现实验。

## 2. 相关工作

- 人群计数（MCNN/CSRNet/P2PNet）；
- 短时预测与滚动验证；
- 疏散规划（时间扩展流）；
- VoI/元推理；
- 人机协同与 AI 风险管理。

## 3. 系统架构

- 感知/预测/VoI/Agent/工具/人员/工单/审批/反馈；
- 安全内核与 Agent 的边界；
- 场景配置与数据契约。

## 4. 方法

### 4.1 VoI 模型

- 先验/似然/后验/熵/风险损失/成本；
- 停止条件；固定/随机/启发式基线。

### 4.2 预测

- 方法集合与滚动验证选择；
- 区间校准与覆盖率；
- 局限：突增不可预测。

### 4.3 规划与独立校验

- 时间扩展最小费用流；
- 15 类硬约束；
- 四态状态机。

### 4.4 人机协同

- 工单状态机、角色权限、上下文版本、幂等；
- 反馈写回与重新评估。

## 5. 实验

- 设置：种子、环境、数据性质；
- A 策略对比（CI/Bootstrap/敏感性/Pareto）；
- B 预测滚动验证（MAE/RMSE/覆盖率/峰值）；
- C 规划扰动与故障注入；
- D 状态机故障注入；
- E 业务闭环；
- F 延迟。

## 6. 结果与讨论

- 成本-收益权衡，不宣称全面最优；
- 预测弱点与区间过度自信；
- 机制有效性 vs 真实安全。

## 7. 局限与伦理

- 合成数据、无真实平台/硬件；
- 不替代现场指挥；
- 隐私与合规；
- 不得用于真实疏散指挥。

## 8. 结论与未来工作

- 真实场景测绘、AgentArts 实机、CANN、公开数据集、持久化/多实例、正式安全评审。
