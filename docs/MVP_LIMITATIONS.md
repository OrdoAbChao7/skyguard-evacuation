# SkyGuard MVP 局限与禁止表述

> 本文件用于**防止过度声称**。任何对外材料引用本仓库时，必须同时引用本文件。
> 安全内核本身的局限仍以 [`LIMITATIONS.md`](./LIMITATIONS.md) 为准。

## 1. 系统性质

- 这是**研究原型 / 辅助决策 MVP**，不是应急指挥系统，不能替代现场指挥员判断。
- 未参与任何真实演练、真实疏散或真实赛事保障。
- 未通过消防、公共安全或功能安全标准认证。
- 测试通过 ≠ 具备实际部署资质。

## 2. 场景数据（合成）

`data/scenarios/stadium-evacuation.json` 是**合成体育场场景**：

- 8 个区域、12 条通道、4 个出口；面积、通行能力、坐标均为 `estimated`；
- 所有摄像机为 `uncalibrated`；
- 工作人员位置、技能、登录码均为演示数据（`source: simulation`）；
- 无人机单位状态为演示状态；
- VoI 先验、似然、损失矩阵、成本权重均为**未标定配置**，不是实测概率；
- 地图是示意拓扑，不是地理坐标，不能用于导航或 GIS。

## 3. 感知

| 路径 | 真实状态 | 禁止表述 |
| --- | --- | --- |
| 模拟观测 | 可用，显式标记 simulation | 不能说成“实时监测” |
| CSV/JSON 回放 | 可用，标记 csv_replay | 不能说成“实时视频识别” |
| CPU 视频计数 | 本机可跑通，无标注精度 | 不能声称准确率/MAE |
| 摄像头健康 | 由最近观测推断 + 场景声明 | 不能声称已接入真实摄像机 |
| 昇腾推理 | **未验证**（无 NPU/CANN/.om） | 不能声称“已完成昇腾适配” |
| 无人机 | **无真实设备**，只有工单请求与模拟反馈 | 不能声称“已控制无人机” |

## 4. 预测

- 算法是 EMA + 线性外推，可解释但不是专用人群预测模型；
- **没有真实标注人流数据**，实验二只用合成序列；
- 实验显示纯线性在该合成数据上略优于 EMA+线性；不能把任一结果当作真实精度；
- 未建模事件突变、拥堵反馈、天气、演出节奏等真实因素；
- 预测区间是残差近似，不是统计置信区间。

## 5. VoI

- 先验、似然、损失与成本来自场景配置，**未经真实场馆标定**；
- 未建模动作之间的相关性、证据重复、取证延迟；
- 损失矩阵是管理偏好，不是物理风险；
- 覆盖权重（邻居/全局）与证据冲突混合系数已移入场景 `investigation.coverage_weights` / `investigation.conflict`，但仍是**未标定启发式**；
- 预算准入统一为 `used + reserved + candidate <= max`（`budget.ts`），但派发时的资源预留尚未与工单系统联动；
- 实验一的结果依赖当前参数与模拟可用性模型，不能推广为“VoI 普遍优于固定策略”；
- 公平复跑（相同动作覆盖 + 观测采样）见 `evaluation/voi-v2/`：多区域总风险收益仍更高，但 V6.2 的效应量被信息权限差异放大，效率优势也小于随机/启发式基线；
- 大模型不参与概率、损失与成本计算——这是刻意的边界。

## 6. Agent 与 AgentArts

| 项 | 状态 |
| --- | --- |
| 本地主干 Agent | 已实现，确定性 VoI + 工具编排，界面标记 `LOCAL DEMO` |
| AgentArts 适配器 | 已实现**官方运行时契约**（`/runtimes/{runtime_name}/invocations`、会话头、`query`/`inputs`）、健康探测、超时、有界多步与契约测试 |
| AgentArts 实机连接 | **未完成**：无租户、凭证、已发布运行时 |
| 状态区分 | `connectivity` 与 `business_closure` 分开；健康成功不升级业务闭环 |
| 界面状态 | 未连通时显示 `AGENTARTS UNAVAILABLE`，**不会**显示为已连接 |

禁止表述：

- “已接入华为云 AgentArts”；
- “AgentArts 平台工作流已验证”；
- “本地规则引擎就是 AgentArts”；
- 引用任何未在租户中实际发生的调用日志。

## 7. MCP

- 标准 stdio MCP Server 已实现，15 个工具通过官方 SDK 客户端测试；
- 新增同进程 Streamable HTTP 端点 `POST /mcp`，与网页 API 共享同一个 `MvpService` 单例；
  测试验证 MCP 创建的工单可被网页侧读取；
- 平台是否支持直接接入 MCP，仍需按租户实际能力验证；
- MCP 的 `submit_worker_feedback` 仅 staff 身份可用；默认 agent 会被拒绝；
- 未做独立 MCP 鉴权层（依赖进程环境与本地信任），公网部署前必须另行加固。

## 8. 人员与工单

- 人员位置、状态、技能为合成数据；
- 登录码是演示身份，不是正式认证；
- 工单/人员状态支持可选 JSON 快照（`OPS_PERSIST_FILE`），Agent 运行记录支持可选快照
  （`MVP_RUNS_FILE`）；**不是数据库**，没有跨工单/预算/事件的共同事务；
- 重启后可恢复上述快照，但证据、会话、预算预留与待发事件仍以进程内为主；
- 单进程单场景；未实现多租户/多场景并发；
- 工单状态机拒绝跳跃，但没有超时自动升级、没有消息通知；
- 审批与派发没有二次确认、没有电子签名。

## 9. 安全与工程

- 读接口默认开放；可通过 `READ_AUTH_REQUIRED=true` 开启读鉴权；
- CORS 默认 `*`，可通过 `CORS_ORIGINS` 收紧；CSP 在生产或显式开启时启用；
- 默认管理员口令 `admin / skyguard2026` 写在文档中，部署前必须修改；
- 未设置 `SECRET_KEY` 时使用开发默认密钥（会打印警告）；
- 已实现进程内限流与请求 ID，但**不是分布式限流**；无审计日志轮转/保留策略；
- 工单/人员与 Agent 运行可选 JSON 快照持久化，**不是数据库**；无事务与多实例并发保护；
- 已提供 Dockerfile 与 CI 配置，但未在真实环境验证运行；
- 安全内核与 Agent 状态仍以进程内为主，重启会重置（快照仅覆盖工单/人员与运行记录）。

## 10. 安全内核

完整保留原有限制：容量静态、1 分钟离散化、无拥堵反馈、无恐慌/逆行建模、
校验器只检查模型内约束、状态机 `NORMAL` 不等于现场安全。详见
[`LIMITATIONS.md`](./LIMITATIONS.md)。

## 11. 可以声称 / 不可以声称

**可以**

- 已实现可运行的 MVP 闭环：感知 → 预测 → VoI 调查 → 人员调度 → 审批 → 执行 → 反馈；
- 本地 Agent 可调用 15 个 MCP 工具，工具调用有权限、Schema、超时与审计；
- 独立校验器与四态状态机在注入故障实验中阻止了错误发布；
- 业务闭环在进程内与 HTTP 集成测试中可重复通过；
- 所有实验、性能与测试结果可在本机复现（固定种子/命令）。

**不可以**

- 声称已在真实体育场部署或验证；
- 声称 AgentArts 已实机接入；
- 声称无人机/昇腾已在真实设备运行；
- 声称预测达到某个真实准确率；
- 声称系统可以用于真实应急指挥。

## 12. V6.5 更新（2026-11-09）

- **资源预留**：已实现人员/预算预留、审批确认、拒绝/取消/过期/失败释放、完成结算、
  幂等指纹与并发同人拒绝；派发前复核人员/上下文/场景版本。仍是单实例；
  预算结算使用工单声明值，不是现场实际耗时。
- **统一状态**：`MVP_STATE_FILE` 提供一次原子快照（安全/工单/预算/Agent/审计），
  含 SHA-256、revision、backup/temp 恢复；损坏或未来版本拒绝启动。
  未实现多实例事务；内存审计视图可能与 JSONL 文件不完全一致。
- **AgentArts**：官方契约、重试、SSE、越权拒绝、反馈续接均已 stub 验证；
  **仍无真实租户、凭证、已发布运行时与平台 Trace**。
- **预测**：新增可靠性字段；区间过宽/数据不足时 VoI 预测动作不可用。
  V6.5 交叉验证中 surge 95% 覆盖率仅 0.738；不得把区间用于安全告警阈值。
- **感知**：新增统一适配器与质量 API。CityStreet 派生帧的“演示面积/密度”由米制多边形计算，
  但无真值、许可未核验、配准近似；只有 surveyed 标定、面积一致、置信度足够时才进入安全域。
  P2PNet 公开数据集结果只证明图像→人数链路，不是现场标定。
- **安全**：HTTP MCP 支持 `MCP_HTTP_TOKEN`；生产未配置 token 时 `/mcp` 返回 503。
  生产 5xx 不回显内部错误消息；Docker daemon 当前未运行，未完成容器实跑。
