# VoI 主动调查模型

> 实现：`backend/src/services/mvp/voi.ts`  
> 参数：`data/scenarios/stadium-evacuation.json` → `investigation`

## 1. 要解决的问题

当区域出现异常或数据不可信时，系统不能只按固定顺序查一遍摄像头。它需要判断：

- 当前对区域状态的不确定性有多大？
- 哪种调查动作最能降低不确定性或降低预期风险？
- 这个动作的时间、资源与失败成本是否值得？

VoI 引擎只负责**排序和停止判断**；概率、损失与成本全部来自场景配置，
不接受大模型生成的数值。

## 2. 数学定义

设区域真实状态为假设 $H_i$，当前信念为 $P(H_i)$：

| 概念 | 公式 |
| --- | --- |
| 先验 | $P(H_i)$，来自场景 `hypotheses[].prior` |
| 似然 | $P(o_j \mid H_i, a)$，按动作类型与假设配置 |
| 后验 | $P(H_i \mid o_j,a) = \dfrac{P(o_j\mid H_i,a)P(H_i)}{\sum_k P(o_j\mid H_k,a)P(H_k)}$ |
| 熵 | $H(B) = -\sum_i P(H_i)\log_2 P(H_i)$ |
| 信息增益 | $IG(a) = H(B) - \mathbb{E}_{o\sim P(o\mid a)}[H(B')]$ |
| 决策风险 | $R(B) = \min_{d}\sum_i P(H_i)L(H_i,d)$ |
| 预期风险降低 | $\Delta R(a) = R(B) - \mathbb{E}_o[R(B'\mid a)]$ |
| 综合评分 | $VOI(a) = w_r\Delta R(a) + w_i IG(a) - w_t C_t - w_c C_c - w_f P_f(a)$ |

其中：

- $C_t = \min(1, t_a / t_{max})$，$C_c = \min(1, c_a / c_{max})$ 是归一化后的时间与资源成本；
- $P_f(a)$ 是动作失败概率；
- $w_r,w_i,w_t,w_c,w_f$ 全部在场景 `weights` 中显式配置；
- 熵使用 bit，风险损失与成本都在 0~1 量纲附近比较。

## 3. 默认场景参数（合成）

| 项 | 值 | 来源 |
| --- | --- | --- |
| 假设 | 平稳 / 快速积聚 / 高危拥堵，先验 0.45 / 0.35 / 0.20 | `stadium-evacuation.json` |
| 结果 | `signal_normal` / `signal_congested` / `inconclusive` / `unavailable` | 同上 |
| 损失 | 平稳：monitor 0 / dispatch 0.15；积聚：0.45 / 0.10；高危：1.0 / 0.05 | 同上 |
| 权重 | 风险 1.0 / 信息 0.5 / 时间 0.25 / 资源 0.2 / 失败 0.3 | 同上 |
| 动作 | 摄像头查询、现场核查、无人机、历史查询、预测 | 同上 |
| 停止阈值 | 0.02 | 同上 |

> 这些数值是**合成演示配置**，未经真实场馆标定。场景文件的 `provenance` 字段会随每次决策输出。

## 4. 动作可用性

VoI 的静态评分之外，运行时还会覆盖可用性：

| 动作 | 运行时条件 |
| --- | --- |
| 摄像头查询 | 摄像头状态必须为 `online`；降级/离线时不可用 |
| 现场核查 | 必须存在满足技能与可达性要求的可用工作人员 |
| 无人机 | 至少一台无人机状态为 `available`，且本身仍需人工审批 |
| 历史查询 | 窗口内至少 2 个可信观测点 |
| 短期预测 | 总是可用，但数据不足时结果会标记 `sufficient=false` |

## 5. 停止条件

满足任一条件即停止调查：

1. 最佳可用动作的 VoI 低于 `stop_threshold`；
2. 达到 `max_investigations`；
3. 没有可用动作；
4. 调查动作转为待人工证据（现场核查/无人机工单），Agent 不再自行继续。

停止后进入：推荐人员、创建待审批工单、转人工或维持监测。

## 6. 策略对照（5 个随机种子 × 200 次）

| 策略 | 工具调用（95% CI） | 风险降低（95% CI） | 时间成本 | 资源成本 |
| --- | --- | --- | --- | --- |
| VoI | 1.819 [1.795, 1.843] | 0.0486 [0.0463, 0.0509] | 1.77 min | 0.226 |
| 固定优先级 | 1.997 [1.994, 2.000] | 0.0572 [0.0546, 0.0597] | 3.57 min | 0.516 |
| 随机 | 2.00 | 0.0500 | 6.06 | — |
| 启发式（信息/成本） | 1.19 | 0.0436 | 2.23 | — |

- Bootstrap 重采样（1000 次）风险降低区间：VoI [0.0462, 0.0511]。
- Pareto：四种策略均未被完全支配；VoI 位于低成本/中收益区域，固定策略是高成本/高收益。
- **不宣称 VoI 全面更优**：它用更少调查与显著更低成本换取了略低的即时风险降低。

### 权重敏感性

单参数缩放 ±50% 时，推荐动作与基准一致的比例：

| 参数 | ×0.5 | ×1.5 |
| --- | --- | --- |
| 风险降低权重 | 1.00 | 0.95 |
| 信息增益权重 | 0.75 | 0.90 |
| 时间成本权重 | 0.95 | 0.75 |
| 资源成本权重 | 0.95 | 0.75 |
| 失败概率权重 | 0.95 | 1.00 |

说明：信息增益与成本权重的变化会改变推荐动作，必须在真实场景重新标定。

## 7. 边界

- 不建模动作之间的相关性（同一摄像头重复查询被当作独立证据被禁止，但未建模观测相关）；
- 似然是场景给出的静态表，未做现场标定；
- 损失矩阵是管理决策偏好，不是物理损失；
- 大模型不参与概率、损失和成本的计算。
