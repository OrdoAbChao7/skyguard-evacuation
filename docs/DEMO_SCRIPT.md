# 6–8 分钟演示脚本（V6 版）

> 全程合成数据；每个关键结论都口头标注“模拟/未实机”。

## 0:00–0:40 定位

大型活动散场：信息不完整、风险传播快、调度靠经验。SkyGuard 做三件事：
**信息价值驱动的主动调查、多区域协同决策、可信安全约束与人机闭环**。

## 0:40–1:30 架构

打开 `docs/MVP_ARCHITECTURE.md`：
感知 → 预测 → 多区域 VoI → 工具（MCP）→ 人员/工单 → 审批 → 反馈 → 重新评估；
安全内核独立（规划器 + 独立校验 + 四态）。

## 1:30–2:40 场景 A 正常散场

1. 大屏点「推演 A」；
2. 指出 NORMAL、预测区间、Agent 判定“数据可信不调查”；
3. 强调：没有无意义工具调用。

## 2:40–3:40 多区域协同（V6 新增）

1. 看“多区域协同调查”面板：
   - 传播风险排序（图模型）；
   - 联合 VoI 动作覆盖多个区域；
2. 点击高优先级区域，地图联动；
3. 说明：总收益更高但单位成本可能更低/更高，取决于预算（如实说）。

## 3:40–5:40 场景 B 局部积聚 + 信息不确定

1. 点「推演 B」：DEGRADED；
2. Agent 控制台：摄像头重试/现场核查/无人机；
3. 审批中心批准、派发；
4. `/staff` 工作人员登录（STF-02/1002）：接单→执行→反馈；
5. 回大屏再运行 Agent：不重复调查，生成疏导工单；
6. 展示工单时间轴完整流转与上下文失效/重新确认。

## 5:40–6:30 场景 C 不可信/容量不足

点「推演 C」：DEGRADED → REJECT；无已验证路线、未解决人数、人工介入。

## 6:30–7:20 证据

- 91 后端 + 8 前端测试；
- `evaluation/COMPETITION_REPORT.md`：VoI/预测/规划/故障注入/闭环；
- `evaluation/V6_REPORT.md`：多区域/重试/邻居预测/多事件；
- MCP 15 工具、权限/幂等；
- 研究库 38 来源、10 笔记。

## 7:20–8:00 边界

AgentArts/昇腾/无人机未实机；预测区间 5/10 分钟未达 95%；
真实测绘/人流缺失；下一步是外部资源验证。
