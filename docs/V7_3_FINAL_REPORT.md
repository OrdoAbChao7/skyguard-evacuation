## 2. 算法贡献

1. **自适应切换惩罚**：随队列压力上升、随风险上升而下降；
2. **A→B→A 振荡检测与惩罚**：区分普通切换与来回振荡；
3. **人群×风险加权切换成本**；
4. **多目标标量化**：到达、完成时间、等待代理、路径暴露、切换；
5. **动态容量一致性**：规划/执行/复核统一按绝对分钟因子；
6. **承诺式求解的容量护栏**：未疏散不增加、逐分钟容量为空、目标劣化护栏、紧急覆盖。

## 4. 负向发现

- 稳定性增加密度/队列/完成时间；
- 动态容量压力抵消部分收益；
- 固定种子单场景中自适应可能比标准 MPC 振荡更多（benchmark 总体更优但不保证逐例）；
- D/E（惩罚/承诺）在切换/安全上接近 F，F 的增量主要来自振荡与自适应权重；
- 安全违规是容量+未疏散代理，不是完整 Validator。
