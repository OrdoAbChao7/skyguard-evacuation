# 人机协同与治理笔记

## 参考

- NIST AI RMF（S25）：风险识别、治理、测量、管理。
- ISO/IEC 42001（S26）：AI 管理体系；本仓库未认证。
- Google PAIR Guidebook（S27）：以人为中心的设计。
- OWASP ASVS（S30）：应用安全验证；本仓库未完整审计。

## 本仓库机制

- Agent 只能创建 `PENDING_APPROVAL` 工单；
- 审批/拒绝/派发要求 admin / safety_operator；
- 接单/执行/反馈要求 staff，且只能操作指派给本人的工单；
- 审批后观测/约束/场景版本变化会使工单 `stale`，派发被阻断，需管理员重新确认；
- 完成反馈写回 `field_report` 观测并触发安全域重算；
- 所有流转写审计与工单 history。

## 设计原则

1. 安全关键动作永远保留人工通道；
2. Agent 的建议必须携带证据、来源与不确定性；
3. 不记录隐藏思维链，只记录可复核的工具调用与决策摘要；
4. 拒绝/降级不是失败，而是安全语义的一部分。

## 缺口

- 演示登录码不是正式身份系统；
- 无电子签名、无二次确认、无移动端推送；
- 无正式人因评估与演练数据。
