# 研究缺口

## 外部访问缺口

1. **AgentArts 官方 API 文档**：2026-11-05 公开检索未找到华为云 AgentArts 的独立 API/鉴权/端点文档，只有产品发布类信息与 ModelArts Studio/API Explorer 入口。因此无法确认以下事项：
   - AgentArts 是否支持直接接入 stdio MCP；
   - 工具/插件注册的真实请求体与鉴权方式；
   - Trace/评估接口的真实结构。
2. **真实租户凭证**：无，无法完成健康探测、工作流调用与平台 Trace 验证。
3. **昇腾设备**：无 NPU/CANN/`.om`，无法实测推理延迟、吞吐与兼容性。
4. **真实视频/人流数据**：无带标注人群视频，无法报告计数精度；预测无真实标签。
5. **真实场地测绘**：体育场面积、通道容量、出口能力均为估算。

## 方法缺口

1. 预测区间覆盖率在 5/10 分钟仍低于 95%（84%/79%），说明突增场景下区间校准不足；需要更多滚动折与真实数据。
2. VoI 参数（先验/似然/损失/成本）为合成配置，未做现场标定；权重敏感性显示部分参数会改变推荐动作。
3. 规划模型无拥堵反馈、无人群动力学；结果是吞吐上界。
4. 安全消融使用注入故障，不能证明真实系统不会漏检未建模约束。
5. 未做正式统计功效分析；实验样本量按可复现性选择，不是功效计算。

## V6 方法缺口

1. 多区域覆盖权重（邻居 0.5/全局 0.3）与风险传播系数是工程启发式，未用真实人群迁移数据标定。
2. 未实现完整 POMDP 信念规划器；序贯调查是 myopic VoI + 预算/重试规则。
3. 邻居信息预测只在共享趋势的合成序列上验证，真实空间相关性未知。
4. 感知评测流程完整，但没有数据集、权重与真实 MAE/RMSE。
5. 多事件规划压力只做了单组合成场景，未做组合爆炸与长期演化。

## 工程缺口

1. 无真实浏览器 E2E（仅组件渲染测试）；无移动端真机测试。
2. 单进程内存状态；可选 JSON 快照不是数据库，无事务/并发写保护。
3. 无多实例、无分布式限流、无审计日志轮转。
4. 无 CI 实际运行记录、无 Docker 实机构建记录（配置可提供）。
5. 正式许可证审计未完成；第三方仓库许可需逐项核验。
