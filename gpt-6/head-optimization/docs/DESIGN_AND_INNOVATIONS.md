# 多机位感知设计、核心创新点与跨版本模型演进

本文档整理 SkyGuard 视觉感知分支（`vision/cchead-head-optimization`）在**多机位区域组合设计**、**人头检测去误检优化**以及**跨版本模型微调与精度对比**上的核心成果，所有数据均来自已留痕实验记录与 CSV 评测结果，可直接用于技术文档撰写与 PR 评审。

---

## 一、多机位监控处理与区域组合设计

针对广场等大范围多机位重叠监控场景，传统做法常对每路独立计数再做跨镜头 Re-ID 融合，但在密集遮挡和低分辨率下极易出现跨镜头 ID 漂移与重复计数。本项目采用**标定先验驱动的空间分治与回退架构**：

### 1. 统一地平面标定与覆盖建图
- 利用 WILDTRACK 七路机位内外参（原始内参 `intrinsic_original`、去畸变内参 `intrinsic_zero` 与外参 `extr_*.xml`），将 7 路视场统一映射至广场正射航拍图（Polyterrasse 主广场约 `3,059 m²`）。
- 七路几何并集覆盖 **`3,007.13 m²`**，两路及以上重叠区 **`1,655.97 m²`**；官方 `432 m²` 标注网格实现几何全覆盖（其中 `422.66 m²` 为两路及以上重叠）。
- 对原去畸变画幅下未覆盖的 `51.84 m²` 西南红区，按原始镜头畸变参数做 `5 cm` 采样复核，精确拆分为 **`27.63 m²` C4 原画幅候选恢复区**与 **`24.21 m²` 七路共同盲区**（无法同时观测地面与 `1.65 m` 头高点），并在地图上分层显式标注。

### 2. 互斥主区划分 + 整区备选回退（区域组合策略）
- 按 `0.20 m` 栅格的**成像头宽、视场边缘余量与实见人流足迹**，将全广场划分为**彼此互斥的固定主区**——每块地面只归一路主控机位负责上报，从空间定义上消除重叠区的重复计数。
- **方案对照与取舍**：在 30 帧官方标注交集上，对比了“逐区逐帧取人数最多一路”动态选路策略：
  - 动态选路虽使 MAE 从 `3.90` 降至 `3.40` 人/帧，但导致 **17 次跨时刻机位抖动切换**，且有 **6 个区时刻误差反而上升**；
  - 试验性交界带去重（`0.45 m` 交界带、`0.65 m` 配对半径，检出 42 对，官方支持同人 29 对/不同人 3 对）使同范围 MAE 从 `3.90` 升至 `4.53` 人/帧。
  - 因此最终确立**先验固定主区为主、交界去重默认关闭（保留对照开关）、仅在主路缺流时启用整区几何覆盖备选机位回退**的稳健组合策略。

### 3. 去畸变检测与原画幅回投闭环
- 模型推理在去畸变图（`intrinsic_zero`）上进行以保持目标尺度一致；回放叠框通过 8 点多边形经 `cv2.projectPoints` 精准回投至原画幅畸变坐标，并强制校验与 `cv2.remap` 的像素偏差 **`≤ 0.5 px`**，确保去畸变检测框画回原视频帧时无畸变错位。

### 4. 标定驱动的三段式去非人头与防“一人多框”
在 WILDTRACK 逐帧回放中发现，经高密度小目标微调的模型二在近景大目标上存在尺度偏移（易把深色外套、衣袋、手肘、大腿误检为多个 `~20 px` 高分框，同时漏掉近景大头）。在不重训模型的前提下设计三段式后处理（见 [`../demos/wildtrack-7cam-head-replay/README.md`](../demos/wildtrack-7cam-head-replay/README.md)）：
1. **3D 物理头径几何尺度过滤**：按头高 `z = 1.65 m`（高台回退 `2.8 m`）反算候选框中心处真实人头（直径约 `0.25 m`）的预期像素直径 `d_exp`，仅保留 `0.52×d_exp ≤ size ≤ 1.85×d_exp`、非边缘长宽比 `0.38～1.9`、`conf ≥ 0.30` 的框。
2. **近远景双模型分带融合**：以 `d_exp = 66 px`（1080p 口径）分带，近中景用原版 YOLOv8s-Head，远景用模型二并保留高分原版框（`conf ≥ 0.45`），交界处做 IoU / 中心距去重（`C2` 保持原版）。
3. **零延迟 `[t-1, t+1]` 2 帧防闪烁**：离线回放采用前后邻帧确认，剔除单帧背景闪烁且零延迟。

实测 7 路 450 帧总框数减少 **8.5%～54.0%**（C5 降 `54.0%`、C6 降 `35.1%`），近景衣裤多框基本消除，且补齐了 C1/C3/C4/C6/C7 原先漏检的近景真头。

## 二、核心创新点提炼

1. **空间先验互斥主区 + 整区备选回退的多机位聚合架构**  
   以标定几何质量与实见足迹做静态主区切分，避免跨镜头重叠区重复计数与动态选路抖动，在无需高开销跨镜头 Re-ID 的条件下实现 7 机位全局汇总与断流容错回退。
2. **基于 3D 物理头径先验的几何尺度过滤与近远景双模型分带融合**  
   将相机标定几何直接引入检测后处理与模型路由：用物理头径约束剔除非人头误检（衣裤/背包/地面框），并用原版权重与微调权重分带互补，同时解决“远景小人头漏检”与“近景一人多框”的尺度矛盾。
3. **按场景密度自适应的切块与大头补检推理策略**  
   针对正俯视中密度（B 组）采用 2×2 重叠切块，针对高密度站台（C 组）采用 2×2 切块 + 全图大头补检（等效短边 ≥ 16 px），在不增加训练成本的前提下将 A–E 五组平均人数 MAE 从模型二全图的 `17.15` 进一步降至 **`9.08` 人/张**。
4. **全链路可审计的镜头映射校验与协议溯源工程体系**  
   从冻结数据划分（`head-count-v2`）、权重 SHA-256 校验、去畸变-回投 `≤ 0.5 px` 数值断言，到 7 路 29.97 FPS 独立带框视频与 2 Hz 汇总地图的严格同步，全流程可复现、可审计、口径透明。

## 三、模型微调过程与跨版本准确率汇总

### 1. 微调轮次与训练过程（`head-count-v2` 冻结划分）

两轮微调均从同一预训练基线（wesjos `v8s-head.pt`，单类 `head`）重新初始化，采用一致的超参数与更新步数，确保跨版本公平对比（详见 [`TRAINING.md`](TRAINING.md) 与 [`results/training_metrics.csv`](results/training_metrics.csv)）：

| 版本 | 初始化起点 | 训练数据构成 | 微调轮次 / 更新步数 | 关键超参 | 末 Epoch 损失 (`box / cls / dfl`) |
| --- | --- | --- | --- | --- | --- |
| **原版基线** (`original`) | wesjos `v8s-head.pt` | 未微调（零样本基线） | 0 | `imgsz=640, conf=0.25, iou=0.50` | — |
| **模型一** (`round1`) | `v8s-head.pt` | Cchead 校园路 `4,003` 张 | `2 epochs` / `8,006` 图次 / `1,063` 次更新 | `imgsz=640, batch=4, AdamW, lr0=0.001, FP32, seed=20261123` | `1.7880 / 0.6324 / 0.6973` |
| **模型二** (`round2`) | `v8s-head.pt` | Cchead `4,003` 张 + RPEE 活动入口 `716` 张（共 `4,719` 张，每 epoch 轮换 `3,396 + 607 = 4,003` 张） | `2 epochs` / `8,006` 图次 / `1,063` 次更新 | 同模型一，末 epoch EMA 权重 | `1.8325 / 0.6848 / 0.7296` |

> **训练过程工程核验**：两轮正式训练前均通过 16 训练 / 16 验证的 `--smoke` 短测验证标签转换、数据轮换与回调修复（首轮短测阶段发现并修正了训练回调错误），每个 epoch 保存可恢复检查点。
